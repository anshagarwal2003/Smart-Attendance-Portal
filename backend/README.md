# Smart Attendance System



Smart Attendance System is a secure web-based attendance management system built using Flask, OpenCV/Face Recognition, SQLite and modern web technologies. It supports Admin, Teacher and Student panels with face verification, blink verification, session code, location verification and attendance reports.



\## Features



\- Admin login

\- Teacher login

\- Student login

\- Course-wise and section-wise management

\- Add students with face photo

\- Add teachers

\- Add timetable

\- Teacher class activation

\- Session code based attendance

\- Face verification

\- Real blink verification

\- Location verification

\- Student attendance dashboard

\- Subject-wise attendance percentage

\- 75% attendance warning

\- Teacher reports

\- Excel export

\- Proof image storage

\- Mobile responsive web interface



\## Technology Used



\- Python

\- Flask

\- SQLite

\- HTML

\- CSS

\- JavaScript

\- face\_recognition

\- OpenCV / Camera API

\- MediaPipe FaceMesh

\- openpyxl



\## Default Login Credentials

## Login Credentials

Login credentials are created and managed by the Admin.

For testing/demo purpose, the system automatically creates sample accounts when the database is empty.

### Admin

Admin credentials can be configured from the database or initial setup.

### Teacher

Teacher accounts are created by the Admin from the Admin Dashboard.

### Student

Student accounts are created by the Admin from the Admin Dashboard.
