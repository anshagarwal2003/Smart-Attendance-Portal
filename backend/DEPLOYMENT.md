# Smart Attendance Deployment

## Recommended: Render with Docker

This project uses `face_recognition`, which depends on native `dlib` libraries. Docker deployment is recommended because it installs the required Linux system packages.

### Steps

1. Push the `backend` folder to GitHub.
2. Open Render and create a new Blueprint from this repository.
3. Render will read `render.yaml` and create the web service with a persistent `/data` disk.
4. Keep these environment variables:
   - `DATA_DIR=/data`
   - `FLASK_DEBUG=0`
   - `SECRET_KEY` generated by Render
5. The app starts with:

```bash
gunicorn --bind 0.0.0.0:$PORT --workers 1 --timeout 120 wsgi:app
```

### Notes

- SQLite, uploaded student images, proof images, and exports are stored under `/data` in production.
- The first request/import initializes the database automatically.
- For a real public college deployment, consider moving from SQLite to PostgreSQL and storing images in cloud storage.
